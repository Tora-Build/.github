# Tora Build

Independent protocol studio, on chain since 2018. We design and ship on-chain systems for markets, liquidity, settlement, privacy and agents.

[Website](https://tora.build)

## Sooth

Prediction markets. One Factory deploys many nodes, and each node has its own operator, pool and order book. [Docs](https://sooth.market/docs) · [Markets](https://sooth.market)

- [sooth-factory](https://github.com/Tora-Build/sooth-factory): Solidity contracts. Experimental. The current revision has no independent external audit.
- [sooth-sdk](https://github.com/Tora-Build/sooth-sdk): TypeScript SDK and CLI.
- [soothsayer-core](https://github.com/Tora-Build/soothsayer-core): Prediction market plugin for AI agents.
